# Pocket Battle Lab

Portrait 1v1 battle tester for the 151 Kanto Pokémon with modern (Gen 5+) mechanics. Static site: `index.html`, plain ES modules, no build step.
UI is Vietnamese; Pokémon, move, item and ability names stay English. No official artwork: creatures are drawn as type-coloured placeholder plates (`js/art.js`, one function, `monArt`).

## Run
```sh
python3 -m http.server 8000    # then open http://localhost:8000/  (fetch() needs http, not file://)
```
All URLs are relative, so it works under a sub-path such as `/pocket-battle-lab/`.

## What you can set (per side A / B)
species (search), level, nature, IV 0-31, EV 0-252 (510 total, remaining shown), live final stats, ability, held item, 4 moves
(learnset by default, "Mọi chiêu" = any move), random legal set, reset, named presets in localStorage, and the whole A-vs-B setup
(+ seed + mode) in the URL hash (`#m=...`, button "Sao chép liên kết").

## Battle
Manual (pick a move per side, then "Lượt") or auto (AI picks the best move), "Chạy tới cuối", "Chạy nhanh" (no VFX), and "Mô phỏng 1000 trận"
(win rate A/B/draw, average turns). Seeded RNG: same seed + same choices = same battle.
Move VFX come from our own CC0 site https://poke5121999-art.github.io/pocket-battle-vfx/ (fx.json + sheets loaded at runtime); if it
cannot be reached the plate just flashes.

## Files
| path | what |
|---|---|
| `js/engine.js` | pure battle engine (stats, type chart, damage, status, items, abilities, AI, simulate); runs in browser and node |
| `js/app.js` | UI: setup panels, pickers, presets, URL hash, battle screen, log, sim |
| `js/vfx.js` | VFX player (canvas, additive light layer) |
| `js/art.js` | placeholder art + type colours |
| `data/*.json` | generated by `tools/build-data.py` from `~/handoff/pkgen1` CSVs |
| `tools/build-data.py` | CSV -> JSON converter (the lever: re-run after the research changes) |
| `tools/coverage.mjs` | writes `docs/coverage.md` (partial move / ability / item counts) |
| `tools/fuzz.mjs` | random builds, all moves, reports crashes / endless battles |
| `tests/engine.test.mjs` | `node tests/engine.test.mjs`: stats, type chart, hand-computed damage, determinism, mechanics |
| `tests/e2e.mjs` | Playwright walkthrough at 390x844 with screenshots and a zero-console-error gate |

## Regenerate / test
```sh
python3 tools/build-data.py          # data/*.json
node tools/coverage.mjs              # docs/coverage.md
node tests/engine.test.mjs
node tools/fuzz.mjs 3000
node tests/e2e.mjs http://localhost:8000/ ./shots     # needs playwright-core + chromium
```

## Deploy
Push the folder contents to the `main` branch of the `pocket-battle-lab` repo and enable GitHub Pages (root). Nothing else to build.
